# Retail action experiments

These schemas and examples are preserved design experiments. They are not part
of Dealer Agent Protocol 0.1, are not advertised by a conformant version 0.1
gateway, and receive no compatibility or conformance guarantee.

The directory contains earlier explorations of personalized quotes, soft holds,
appointments, consent, and human handoff. Promoting any of them would require a
separately versioned extension with its own privacy, authorization, consent,
confirmation, retention, and behavioral test requirements.
