What the public Gateway processes when it serves dealer-authorized retail inventory.

Applies toGateway websiteHoward Bentley MCP endpointProtocol privacy policy

Summary

The website has no user accounts, advertising, payment processing, or behavioral analytics. The public endpoint serves approved retail vehicle facts from Howard Bentley Buick GMC’s dealer-authorized daily feed. It does not expose customer records, source credentials, inventory age, stocked dates, invoice, book value, or other dealer-private fields. We do not sell personal information.

Gateway requests and query receipts

The Gateway processes MCP or REST request bodies, protocol metadata, timestamps, response status, and errors to answer requests, prevent abuse, and diagnose failures. Inventory searches create a dealer-visible query receipt containing the query text, result count, limited result VINs, timing, source, and outcome. Email addresses and phone numbers detected in query text are redacted before storage. The Gateway does not store a client IP address in the dealer query receipt. Do not submit names, contact information, credentials, customer records, confidential dealer data, or other sensitive information.

Infrastructure data

Cloudflare may process standard network information such as IP address, date and time, requested URL, user agent, routing data, and security events to deliver, rate-limit, and protect the service. The Gateway derives a one-way rate-limit key from request network metadata but does not write the underlying IP address to its application database.

Service providers

Cloudflare hosts and protects the sites and endpoint and may process network data under its Privacy Policy. Google Fonts supplies web fonts under the Google Privacy Policy. GitHub hosts public collaboration under the GitHub Privacy Statement.

Use, disclosure, and retention

Operational information and query receipts are used to operate and secure the service, understand aggregate shopping demand, investigate failures or abuse, and improve retail answers. Information may be disclosed when required by law, to protect the service or others, or to providers performing those functions. It is not sold or shared for targeted advertising and is retained only as reasonably needed for those purposes and legal obligations.

Rights, children, and contact

Privacy rights vary by location. These developer and retail-discovery services are not directed to children under 13. For a privacy request, email ariel@dealergrowthhackers.com. Do not include sensitive information in a public GitHub issue. Security reports should use private vulnerability reporting.

Changes

Material changes will be posted here with a revised effective date. This transparency statement is not legal advice; qualified counsel should review the policy as the commercial service evolves.
