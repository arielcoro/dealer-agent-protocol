A controlled retail boundary

Agents get the answer. Not your systems.

DealershipMCP is a Dealer Agent Gateway: it normalizes approved retail sources into the open Dealer Agent Protocol and serves typed MCP tools to AI assistants.

The boundary

Inventory feeds, pricing policies, incentive data, and authoritative availability remain behind dealer policy. The gateway publishes only the fields needed to answer vehicle-shopping questions. It is not generic access to your DMS, CRM, customer records, desking, lender decisions, or contracts.

Customer data enters through one door

01

Prepare

The agent asks for purpose, channels, and data categories. No name, email, or phone is sent.

02

Disclose

The gateway returns the exact disclosure and an ES256-signed, expiring, single-use binding.

03

Consent

The buyer sees the disclosure and chooses whether to continue.

04

Deliver

The gateway verifies every binding condition, then emits one tagged ADF lead.

Failed verification means nothing is stored and nothing is forwarded. Binding tokens and contact data never appear in URLs, logs, metrics, errors, cursors, or cache keys.

Open standard, hosted product

Dealer Agent Protocol defines the portable tools, schemas, and conformance tests. DealershipMCP is one commercial implementation from Dealer Growth Hackers. Other vendors can implement the same Apache-2.0 standard.
