Dealer-controlled publication

One approved feed makes your store agent-ready.

Start without opening the DMS. Publish a Dealer Agent Protocol discovery file and a scheduled inventory export, then graduate to a managed Gateway as the pilot proves value.

What your website can publish

  1. /.well-known/dealer-agent.json identifies the dealer and rooftops, points to the retail feed, and declares the authority policy.
  2. A dealer-agent-inventory-csv/0.1 feed carries vehicles, advertised price, required charges, conditional offers, source time, and asserted availability.
  3. A public declaration tells agents where the dealer-approved source lives.
Honest by design: a scheduled feed may say “dealer-asserted,” but never “verified now.” A managed gateway upgrades availability only after an authoritative check.

Your two paths

Use the open standard: implement the specification, schemas, examples, and conformance tests under Apache-2.0.

Use the managed product: start with the free diagnostic options. If the fit is right, we map the existing export and operate the dealer-specific Gateway.
