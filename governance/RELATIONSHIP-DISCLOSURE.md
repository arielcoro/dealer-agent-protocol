# Editor and implementation relationship

Dealer Agent Protocol was created by Ariel Coro and is governed as an open Apache-2.0 project. Dealer Growth Hackers operates DealershipMCP, a commercial implementation of the protocol, and may benefit when dealers adopt that product.

That relationship is disclosed on both websites and in protocol governance. DealershipMCP receives no private specification access, reserved conformance status, or exclusive implementation right. Competing gateways may implement and claim the same profiles under the same published tests. Protocol changes require a public interoperability case, review record, and disclosed conflicts.

The independent dealer co-chair seat is intentionally open until a dealer accepts it. The project will not fabricate neutrality by naming a nominal or affiliated placeholder.
