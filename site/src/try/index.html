Paste one URL. Ask a real question. Get the answer with its evidence.

Connect Claude, ChatGPT, Claude Code, Cursor, or any MCP client to a Dealer Agent Gateway and watch an agent read inventory, verify availability, itemize a price, and ask for consent before it shares a single contact detail.

01 / Connect in two minutes

Pick your client. Paste the endpoint. Done.

No account, no API key, no SDK. The gateway is a plain MCP server over Streamable HTTP, so every current host can reach it the same way.

Claude

  1. Open Settings → Connectors and choose Add custom connector.
  2. Name it Example Motors (DAP demo), paste the endpoint, and choose No sign-in. If Claude offers a sign-in step anyway, choose Connect to skip it.
  3. Start a new chat. Claude asks before the first call to each tool; Always allow is safe for every read tool.

ChatGPT

  1. Turn on Developer mode under Settings → Apps & Connectors (a workspace admin may need to allow it).
  2. Choose Add custom MCP server, name it, paste the endpoint, and select No authentication.
  3. In a new chat type @ and pick the connector. Results render as cards; the consent step shows the exact disclosure text.

Claude Code

claude mcp add --transport http dap-demo https://demo.dealeragentprotocol.com/mcp

Then ask: “Using dap-demo, which new SUVs under $40,000 does Example Motors have, and is the cheapest one verified available?”

Cursor, VS Code, and any MCP client

{
  "mcpServers": {
    "dap-demo": { "url": "https://demo.dealeragentprotocol.com/mcp" }
  }
}

Inspect the raw contract without a model:

npx @modelcontextprotocol/inspector --cli https://demo.dealeragentprotocol.com/mcp --transport http --method tools/list
02 / Ask these

Five questions that show what a gateway should refuse to guess.

Each one exercises a different part of the contract. The notes say what a correct answer looks like, so you can judge the agent as well as the gateway.

  1. “What SUVs does Example Motors have under $40,000?”

    The agent should call inventory.search with a price filter in minor units, list results with advertised price and whether required dealer charges are included, and say that search results are discovery snapshots.

  2. “Is the 2026 Northstar Touring still available? Show me the evidence.”

    Expect a separate verify_availability call, the authority class authoritative, an observation time, and a validity window. For the used 2024 Northstar the same question must come back as could not be verified, because its evidence is deliberately stale.

  3. “What does stock N26001 really cost with fees and incentives?”

    The pricing disclosure separates the advertised price, a documentation charge that is already included, a military incentive with its verification requirement, and government charges marked unknown. A good agent never turns unknown into zero.

  4. “Tell me about the used 2024 Northstar: miles, how long it has been on the lot, and its history.”

    Inventory age arrives with its clock (stocked date) and as-of time. Two history providers disagree about an accident and the gateway leaves that conflict visible instead of picking the better story.

  5. “Have the dealer email me about N26001.”

    The agent should read the handoff policy, prepare a signed binding without asking for your email, show you the exact disclosure text, and only then submit. The ADF/XML comes back to the agent and is never delivered. Try submitting the same binding twice: the second attempt is refused.

03 / Why this demo looks different

Other demos show that an agent can call a dealer. This one shows what the agent is allowed to claim.

  1. ALabeled sandbox, not a scraped store

    The fleet is synthetic and says so in every response, the manifest, and the policy. No real dealer's listings were copied to make the demo work.

  2. BAvailability has a source and a clock

    “Available” carries an authority class, observation time, and validity window. Stale evidence returns dealeragent.vehicle.stale instead of a daily snapshot dressed up as now.

  3. CPrice is a disclosure, not a display string

    Advertised price, required dealer charges, conditional adjustments with eligibility and stacking rules, and government charges are separate typed components in integer minor units.

  4. DConsent before contact, verifiable by anyone

    The binding is an ES256 JWS over the disclosure digest, purpose, channels, subject, and expiry. The public key is published at /.well-known/jwks.json, so a third party can verify it without trusting the gateway.

04 / Under the hood

Ten tools, six profiles, every schema public.

The gateway validates every request against the normative JSON Schemas and returns structured content plus a plain-text summary. Hosts that support MCP Apps render the structured content as cards.

dealeragent.discovery.get_manifest

Know the server

Profiles, tools, rooftops, policies, freshness SLAs, conformance state, JWKS.

dealeragent.dealer.get

Who is selling

Organization and rooftop identity, addresses, hours, public contacts.

dealeragent.inventory.search

Discover

Typed filters, sort, facets, signed cursors, provenance and freshness per result.

dealeragent.inventory.get_vehicle

One exact record

By vehicle_id, VIN, or stock number inside one rooftop.

dealeragent.inventory.verify_availability

Verify

Authority class, observation time, validity window, refusal when stale.

dealeragent.pricing.get_disclosure

Explain the price

Advertised price, required charges, conditional adjustments, government-charge status.

dealeragent.inventory.get_used_vehicle_details

Used-vehicle evidence

Odometer, dated tenure, provider-specific history, title, inspection, certification, conflicts.

dealeragent.handoff.get_policy

Ask before asking

Accepted purposes, channels, data categories, the exact disclosure text.

dealeragent.handoff.prepare · submit

Consented handoff

Signed single-use binding first; contact details only after agreement; sandbox ADF returned, never forwarded.

05 / Run it yourself

Same code, your inventory.

cd dealer-agent-protocol && npm ci
node --test tests/demo-gateway.test.mjs
cd deployment/cloudflare && npx wrangler dev --config reference-gateway.wrangler.example.jsonc
