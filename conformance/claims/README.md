# Public conformance claims

This directory is the source for the public claim index. A listing is evidence of a tested profile claim, not certification, legal approval, product endorsement, or a claim about unlisted rooftops.

| Implementation | Data | Profiles | Evidence |
|---|---|---|---|
| Dealer Agent Protocol reference gateway | Synthetic only | Core Retail Read 0.1 | [`example-claim.json`](example-claim.json) |

Production claims will name the implementation, exact profile versions, authorized rooftop scope, test suite/digest, issue/expiry times, and ES256 signature. DealershipMCP receives no special path; every implementation uses the same published schema and behavior suite.
