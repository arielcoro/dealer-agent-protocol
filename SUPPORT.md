# Support

Dealer Agent Protocol 0.1 is an editor's draft and the reference gateway is a
synthetic conformance fixture. There is no production support commitment.

- Use GitHub Discussions for implementation questions and design exploration.
- Use GitHub Issues for reproducible defects and protocol proposals.
- Use GitHub private vulnerability reporting for security concerns.

Do not post credentials, customer data, unpublished dealer data, or private
vehicle records in any public channel.
